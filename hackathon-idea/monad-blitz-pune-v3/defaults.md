# Defaults (written before any search)

Brief: "consumer dApp on a fast, cheap, EVM-compatible chain, built in one day." These are the ideas any model would give with no research. Final ideas that match one of these (same user and job, or same job and mechanism) survive only with a research-backed wedge in `default_match.why_different`.

| # | Default idea | User / job / mechanism | Recycled category it hits |
|---|---|---|---|
| D1 | On-chain casual game (clicker, flappy bird, tap-to-mine, on-chain chess) | gamers / kill time / every move is a tx | generic "on-chain game" (most common fast-chain demo) |
| D2 | Creator tipping / "buy me a coffee" with crypto, per-second streaming tips | fans → creators / support / micro-payment | tipping (very common) |
| D3 | Prediction market on cricket / IPL / elections among friends | friends / bet on outcomes / pooled stakes, oracle resolves | prediction markets (very common; also legally exposed in India) |
| D4 | NFT event ticketing with anti-scalping resale caps | event-goers / buy & resell tickets / NFT ticket with royalty/cap | NFT, token-gated |
| D5 | Social tokens / creator coins / friend.tech clone | fans / speculate on creators / bonding curve | NFT/token-gated, social tokens |
| D6 | Bill splitting / shared expenses settled on-chain (Splitwise on-chain) | flatmates / split costs / on-chain ledger + settle | expense-splitting tracker |
| D7 | On-chain chit fund / ROSCA / committee | group savers / rotate pooled savings / smart-contract pot | "X on-chain" |
| D8 | Pay-per-second streaming (video, music, Wi-Fi, parking) | consumers / pay for usage / streaming micropayment | micro-payment demo |
| D9 | On-chain lottery / raffle / giveaway with VRF | Instagram followers / enter giveaway / verifiable randomness | raffle/lottery |
| D10 | Loyalty points as tokens for local shops | shoppers / earn+redeem points / ERC-20 points | "loyalty tokens" |
| D11 | Real-time multiplayer on-chain game (agar.io / tank battle / trivia with stakes) | gamers / compete live / per-move tx | on-chain game |
| D12 | Crowdfunding / donation tracking with transparency | donors / give and track / escrow + milestone release | crowdfunding |
| D13 | Decentralised social feed / on-chain likes and reactions (pay-per-like) | social users / post and react / each like a tx | "Twitter on-chain" |
| D14 | AI agent wallet that pays for things for you | consumers / delegate purchases / agent + wallet | "an agent that does X" |
| D15 | Gasless onboarding / social-login wallet "for normies" | non-crypto users / get a wallet / account abstraction | infra, not a consumer job |

Generation rule for discovery: keep these in view, seed from real complaints by named user groups (Indian hostel/flatmate groups, college fest organisers, sports turf players, small vendors, fans facing ticket fraud, Instagram giveaway entrants, gig workers, plus at least one non-Indian group) and generate away from the job+mechanism pairs above.
